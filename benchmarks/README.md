# Benchmarks

This directory contains public, reproducible evidence used to evaluate the choices tracked in the integration [decision register](../decisions-and-open-questions.md). Each benchmark keeps its model, policies, tests, runners, and generated results together.

## Available Benchmarks

- [CKB custody flow](./custody-flow/): compares custody-cell selection and change-shaping policies, then models inventory recovery and the committed-cell lifecycle.

Run custody-flow commands from its [package directory](./custody-flow/). Generated results record the command and runtime used to produce them.
